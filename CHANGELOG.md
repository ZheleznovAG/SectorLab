  подключение, приказ, смерть/возрождение, вид узлов, итог, новый матч и обрыв связи.

## 1.1.0 (code 2) — 22.10.2026

Сборка `Builds/Android/SectorLab-v1.1.0.apk` из `672b2a8`, SHA-256
`13EB6EA83621DA87F00EA08499F826EBE387439DCE6D020798D29A0BC5FC9701` ([отчёт](docs/evidence/android-build-v1.1.0.json)).

**Игра вдвоём по Wi-Fi.** Кнопка «Сеть» в шапке: «Создать игру» (вы — синие, хост) или «Подключиться»
по IP (вы — красные). Хост считает партию, клиент показывает её со своей стороны и отправляет приказы;
хост проверяет каждый приказ. Обрыв связи ставит матч на паузу; любой экран ожидания предлагает
«Играть с ИИ»; новый бой начинает хост, клиент входит в него сам.

**По отзыву после партии на 1.0.0:**
- боец, стоящий на узле, снова выбирается тапом по нему;
- бои длиннее: урон снижен примерно в 2,5 раза;
- идущий по приказу боец проталкивается через стоящих союзников;
- рамка по краю поля и подпись показывают, кто сейчас побеждает;
- кольцо захвата вокруг узла: прогресс и сторона видны краем глаза.

**Внутри:** бой считается по тику матча, а не по кадрам; приказы — данные с проверкой;
реактивная модель матча на R3; итог «Победа/Поражение/Ничья» по-русски.

**Проверено:** EditMode 76/76, PlayMode 154/154; сетевая партия Editor + Windows-плеер на одном ПК.
