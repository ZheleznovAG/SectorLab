# Контекст, подтверждённые решения и реальное состояние

**Состояние на 10.10.2026:** документ описывает решения в разговоре, **не результат аудита файлов пользователя**.

## Что известно из обсуждения

- Рабочее название Unity-проекта — **SectorLab**. Прежнее имя MicroTactics снято с актуального плана.
- Назначение: небольшой мобильный тактический/стратегический прототип, который можно понять, развить и показать при отклике на Unity-вакансию Gear Games.
- Важнее не скоростная генерация кода, а **осознанная самостоятельная разработка малыми шагами**.
- Предпочтение: **3D top-down**, Unity 6 LTS, URP, на ПК разработка, Android — целевая платформа. Точный установленный релиз Unity и набор пакетов требуют локальной проверки.
- Направления игры обсуждались: захват точек, отряд дронов, конвой, заражённая станция, сбор ресурсов и др. **Жанр/основная механика не утверждены.**
- Целевые технологии для изучения: C#, Unity Input System, Prefabs, ScriptableObject, Unit Tests, UniTask, VContainer, Addressables, профилирование. **Нет утверждения, что они уже установлены или освоены.**
- Раньше были подготовлены `SectorLab_R0.zip` и установщик, создающие сцену автоматически. После этого пользователь **явно предпочёл не использовать крупный автогенерируемый старт**, а пройти создание сцены и настройку вручную с небольшими коммитами.

## Что НЕ подтверждено

- Создан ли локальный `SectorLab`, корректно ли он открывается.
- Установлен ли прежний пакет R0.
- Инициализирован ли Git, есть ли коммиты/ветки/незакоммиченные правки.
- Какие сцены, скрипты, настройки Unity и пакеты существуют.
- Есть ли подключённый Android-девайс/средства сборки.
- Используется ли Input System или старый Input Manager.

Не выставлять ни одному этапу статус `готово` без проверки репозитория или подтверждения пользователя.

## Первый протокол агента

**Если есть доступ к локальному репозиторию**, безопасно прочти (не меняя файлов):

```powershell
Get-Location
Get-ChildItem -Force
if (Test-Path .git) { git status --short; git log --oneline -n 8 }
if (Test-Path Packages/manifest.json) { Get-Content Packages/manifest.json }
Get-ChildItem Assets -Recurse -File -ErrorAction SilentlyContinue | Select-Object -First 80 FullName
```

Также открой `ProjectSettings/ProjectVersion.txt`, существующие `.unity`, C#-скрипты и документацию. Не выводи установленные пакеты исключительно из планов.

**Если доступа нет**, запроси у пользователя только минимально необходимое подтверждение текущего состояния и дай первый безопасный ручной шаг.

## Предлагаемая стартовая отметка

- Планирование R0: **сформировано**.
- Реализация R0.0–R0.8: **неизвестно, требует проверки**.
- R1+: **не подтверждено**.
- Конкретная механика игры: **открытый вопрос**.
