# Контекст, подтверждённые решения и реальное состояние

**Состояние на 11.10.2026:** проверено по репозиторию и в открытом Unity Editor (через Unity CLI). Статус этапа по-прежнему определяется фактическим содержимым репозитория, а не этим текстом.

## Что известно из обсуждения

- Рабочее название Unity-проекта — **SectorLab**. Прежнее имя MicroTactics снято с актуального плана.
- Назначение: небольшой мобильный тактический/стратегический прототип, который можно понять, развить и показать при отклике на Unity-вакансию Gear Games.
- Важнее не скоростная генерация кода, а **осознанная самостоятельная разработка малыми шагами**.
- Направления игры обсуждались: захват точек, отряд дронов, конвой, заражённая станция, сбор ресурсов и др. **Жанр/основная механика не утверждены.**
- Целевые технологии для изучения: C#, Unity Input System, Prefabs, ScriptableObject, Unit Tests, UniTask, VContainer, Addressables, профилирование. Из них подключён только Input System (как пакет шаблона); остальные не установлены и не освоены.
- Прежний `SectorLab_R0.zip`/установщик **не использовался**: проект создан с нуля из шаблона URP.

## Подтверждено по репозиторию

- Проект: `[LOCAL_USER_HOME]\Projects\SectorLab`, Git-репозиторий, remote `origin` — GitHub `ZheleznovAG/SectorLab`, ветка `main`.
- Unity **6000.6.4f1**; URP **17.6.0** (ассеты Mobile/PC в `Assets/Settings/`); Input System **1.20.1** (`activeInputHandler` — новая система). Unity Test Framework не подключён.
- Сцена `Assets/_Project/Scenes/Main.unity` — единственная, она же в списке сборки. Содержит камеру, направленный свет и арену 10×10 м. Собственного C#-кода нет.
- Активная платформа — Android (Build Profile `Assets/Settings/Build Profiles/Android.asset`). Android SDK/NDK установлены вместе с Unity.
- APK собирается без ошибок (`Builds/Android/SectorLab.apk`, ~29 МБ). **Запуск на устройстве не проверялся** — устройство не было подключено.
