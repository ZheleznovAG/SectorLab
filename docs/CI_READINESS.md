# Проверки проекта

Решение владельца от **27.10.2026**: использовать локальные Unity-проверки и существующий
быстрый CI GitHub. Подключение облачных сервисов Unity в план не входит.
[ADR-024](adr/024-local-unity-validation.md).

## Рабочий процесс

| Проверка | Где выполняется |
|---|---|
| Python 3.9/3.14, гигиена, Gitleaks | GitHub Actions на push/PR, `checks.yml` |
| Unity EditMode и PlayMode | Локальный установленный Editor, `Tools/sl.py test` |
| Android/Windows build и упаковка Addressables | Локально, `Tools/sl.py build-*` |
| Два Windows-процесса по UDP | Локально, `Tools/sl.py verify-network` |
| Android: управление, звук, FPS, память, Wi-Fi | На физическом устройстве |

Для обычной работы не требуются новая организация Unity Cloud, подписка или передача
личного пароля Unity в GitHub. Используется уже установленный и активированный локальный Editor.

## Перед фиксацией изменений

```sh
python Tools/sl.py test --task <новое-имя> --mode PlayMode --filter SectorLab.Tests.<Fixture>
python Tools/sl.py test --task <другое-новое-имя>
python Tools/sl.py check
```

Нужен открытый Editor с проектом. Имена прогонов не должны совпадать с существующими evidence.
При изменении упаковки дополнительно собрать целевую платформу; Android-приёмка на телефоне
остаётся отдельной проверкой. Команды и окружение — [DEVELOPMENT](DEVELOPMENT.md).

Текущая подтверждённая база — **88 EditMode + 172 PlayMode**, **16 UDP-проверок**;
[доказательства](review/REMEDIATION_2026-10-27.md). Изменение правил CI не переписывает эти результаты.

## Ручной GameCI

`tests.yml` сохранён как необязательный эксперимент с единственным триггером `workflow_dispatch`.
Он не запускается на push/PR. Если его когда-либо запустят вручную, потребуется отдельно
подтверждённое лицензирование; без секретов preflight явно завершится ошибкой.
Настройка этого эксперимента не является текущей задачей проекта.

## Пределы автоматизации

Локальные Unity-тесты не публикуют обязательный PR-check автоматически и сами по себе
не запрещают merge в GitHub. R-03 в части автоматического Unity-gate отложен по решению владельца.
Основные следующие шаги — Android-приёмка и улучшение самой игры; облачная миграция не требуется.
