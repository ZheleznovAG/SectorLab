# ADR-019 — Звук из модели и сглаживание клиентских прокси

**Дата:** 2026-10-26  
**Статус:** принято

## Контекст и проблема

Локальные события выстрела и тика не возникают на сетевом клиенте. Перемещение прокси
непосредственно на координаты каждого кадра заметно при частоте сети 10 Гц.

## Варианты

- Отдельные надёжные события звука: требуется подавлять поздние повторы и догоняющие очереди.
- Общая модель со счётчиками: уже передаётся в полном снимке, применима к обоим режимам.
- Предсказание движения: сложнее согласовать с NavMesh; для этой игры пока не требуется.

## Решение

MatchAudio слушает завершённые изменения MatchModel. Счётчик выстрелов внутри поколения бойца
даёт максимум один текущий звук при пропуске нескольких кадров; первый снимок и новое поколение
задают исходное состояние. Повтор кадра и снятие mute не воспроизводят историю. Узлы сравниваются
с предыдущим завершённым состоянием. Прогноз выдерживается одну секунду игрового времени хоста,
без продвижения на heartbeat паузы. Итог продолжает поступать из Model.Outcome.

ClientMotion переводит отображаемую позицию к последней полученной за 100 мс. Следующий пакет
начинает переход от текущей отображаемой позиции: нет скачка назад при неравномерном поступлении.
При отсутствии пакетов движение останавливается на известной позиции. Смерть скрывает прокси,
новое поколение/матч переносит его сразу. Пауза сразу устанавливает авторитетную позицию.
ClientUnitView обновляет единый transform для геометрии и коллайдеров выбора.

## Последствия

Визуальная задержка до 100 мс; предсказания, отката и движения за последнюю известную точку нет.
В runtime не создаются очереди исторических звуков. Локальные правила боя и частота тика сохранены.
Параметр сглаживания пересматривается по результатам игры в реальной сети.

## Проверка

ClientPresentationTests проверяет повторные кадры, пропуски выстрелов, новое поколение, mute,
таймер прогноза и паузу. ClientMotionTests проверяет непрерывность, остановку без пакетов,
смерть, пропущенную смерть перед респауном, новый матч и отключение.
Полный прогон `model-audio-motion-full`: **86 EditMode + 164 PlayMode PASS**.
