# 12. Release checklist SectorLab v1.0

## Репозиторий

- [ ] Ветки/HEAD и актуальный Git status проверены; неизвестных изменений нет
- [ ] Старые 35 коммитов сохранены, новые логически осмысленны
- [ ] Нет секретов, билдов, Unity Library/Temp, случайных бинарников
- [ ] Метаданные `.meta`, Addressables config, manifest и lock включены корректно
- [ ] Git LFS реально установлен/корректен или его отсутствие явно помечено
- [ ] README/требования/ADR/лицензии обновлены по фактическому коду

## Игра

- [ ] Матч 3×3 с Tank/Scout/Ranger
- [ ] A/B приносят очки, C лечит, можно contest/capture/neutralize
- [ ] Счёт и время независимы от FPS, пауза работает
- [ ] Противник борется за контроль, доступны победа/поражение/ничья
- [ ] Юниты повторно появляются, нет дубликатов или пропавших правил
- [ ] Работает tap/camera drag/pinch/UI blocking; команды читаемы
- [ ] HUD, SFX/mute, restart, ошибочные загрузки обрабатываются
- [ ] Есть короткая инструкция, минимум одна реально сыгранная партия

## Инженерия

- [ ] VContainer зарегистрирован и реально используется
- [ ] UniTask имеет реальную асинхронную цепочку, cancel/error обработаны
- [ ] Addressables создаёт prefab в настоящей игре и освобождает ресурсы
- [ ] Есть тесты захвата, счёта, времени, смерти/respawn, restart/load/cancel
- [ ] EditMode+PlayMode регрессия прошла на финальном SHA **или честно BLOCKED**
- [ ] Android APK собран после контента; прошёл device test **или честно BLOCKED_DEVICE**
- [ ] Профилирование приложено либо ограничение явно названо
- [ ] `IMPLEMENTATION_STATUS.md`, `EVIDENCE_REPORT.md`, `STUDY_WALKTHROUGH.md` соответствуют реальному состоянию

## Запрет на формальную галочку

Пункт закрыт только после свидетельства. Если телефон отсутствует, можно закончить реализацию, но нельзя объявить релиз полностью проверенным на Android. Пользователь не должен узнавать об этом только из мелкого примечания.
