# 09. Критерии приёмки и доказательства готовности

## Общая граница

В финальном отчёте отделять:

- **Implementation complete** — функциональность и тесты реализованы в репозитории;
- **Editor verified** — реально запускалась сборка/сцена/тесты Unity;
- **APK built** — действительно собран свежий Android APK;
- **Device verified** — выполнен запуск на настоящем Android;
- **Playtest verified** — настоящий пользователь играл, а не скриптовая симуляция;
- **Release ready** — выполнены все применимые критерии публикации, включая устройство и пользовательскую проверку.

Последнее не подменять первым.

## Acceptance gates

| Gate | Обязательный результат | Доказательство |
| --- | --- | --- |
| G0 | Старый код и изменения сохранены, история реальная | HEAD до/после, Git status, упорядоченные коммиты |
| G1 | Матч по очкам, время/пауза/ничья | EditMode+PlayMode + Game View |
| G2 | A/B/C capture+score+heal | Tests capture/contested + сцена |
| G3 | Противник сражается за узлы, матч завершается | AI тесты, несколько матчей |
| G4 | VContainer действительно управляет службами матча | Ссылка на scope и внедрение, PlayMode |
| G5 | UniTask и Addressables реально участвуют в создании юнитов, cleanup корректен | Integration tests, ошибочная загрузка, cancel/restart |
| G6 | Мобильное управление и HUD | Virtual touch + скриншоты форматов; телефон если есть |
| G7 | Игра понятна другому человеку, не разрастается | Ручная игровая проверка, краткая инструкция |
| G8 | Регрессия и Android сборка проходят | Логи Unity, APK build, профилирование где доступно |
| G9 | README/ADR/технический отчёт/лицензии/Git чисты | Навигация по репо, точные SHA и статус тестов |

## Таблица итоговых доказательств (`EVIDENCE_REPORT.md`)

Для каждого Gate:

```
Gate: G5
Commit: <actual sha>
Environment: <Unity version, OS, runtime>
Code paths: <files/classes>
Checks performed: <exact commands/manual steps>
Result: PASS | FAIL | BLOCKED
Logs/screenshots: <actual paths or "none">
Limitations: <what remains unverified>
Next action: <if any>
```

**Нельзя:** вставлять заранее заполненные PASS, хеши несуществующих коммитов, рисовать скриншоты вместо фактических, ссылаться на исходную APK как на сборку финальной версии.

## Формат финального отчёта агента

1. Чего достигла версия и что игрок делает на экране.
2. Список проверенных gates G0–G9 и MUST FR/NFR с PASS/FAIL/BLOCKED.
3. Реальные коммиты первого и последнего шага, общая краткая история; чистота дерева.
4. Тесты и фактические результаты + лог-файлы.
5. Архитектурные решения и ограничения; список зависимостей/лицензий.
7. Что осталось/что пользователь должен проверить вручную.
8. Порядок изучения коммитов и кодовых модулей.
