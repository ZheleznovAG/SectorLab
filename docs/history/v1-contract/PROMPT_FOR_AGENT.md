Затем предложи **ровно одну ближайшую микроитерацию** в формате: цель → зачем → ручные действия → минимальная теория → проверка → вопрос на понимание → возможный Git-коммит. Объясняй по-русски, не прячь знания за терминологией. Не приписывай мне коммерческого опыта с VContainer, UniTask и Addressables. Основная игровая механика ещё не утверждена, поэтому не превращай SectorLab автоматически в игру про захват точек.
