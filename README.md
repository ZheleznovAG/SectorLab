# SectorLab

Учебный прототип мобильной тактической игры на Unity: 3D, вид сверху, целевая платформа Android. Проект развивается маленькими проверяемыми шагами по [`docs/03_ROADMAP.md`](docs/03_ROADMAP.md). Основная механика пока не выбрана (см. [`docs/06_GAME_DESIGN.md`](docs/06_GAME_DESIGN.md)).

**Текущее состояние:** R3 — короткая законченная партия: 3 твоих юнита против 3 врагов на арене 10×10 м, победа, поражение и перезапуск. Цель «уничтожить всех врагов» — временная заглушка, основная механика ещё не выбрана (DEC-007).

![Партия R3](docs/images/r3-match.png)

## Как играть

- **Нажми на синего юнита** — он выделится жёлтым кольцом.
- **Нажми на землю** — выделенный юнит пойдёт туда (жёлтый маркер — точка назначения).
- **Нажми на красного врага** — выделенный юнит подойдёт и будет атаковать.
- Стоящие юниты сами атакуют ближайшего врага: твои — в радиусе 2.5 м, враги — 4 м. Подводи врагов по одному.
- Победа — все враги уничтожены, поражение — потеряны все твои юниты. Кнопка **Restart** начинает партию заново.

Мышь в редакторе и касание на телефоне обрабатываются одним кодом (`Pointer` из Input System).

## Требования

- Unity **6000.6.4f1** с модулем **Android Build Support** (OpenJDK, Android SDK & NDK).
- Git и **Git LFS** (бинарные ассеты хранятся через LFS).

## Запуск

1. Клонировать: `git clone https://github.com/ZheleznovAG/SectorLab.git`, затем `git lfs pull`.
2. Открыть папку проекта через Unity Hub.
3. Переключить платформу: **File → Build Profiles → Android → Switch Platform** (активная платформа хранится в `Library/`, поэтому свежий клон открывается под Windows).
4. Открыть сцену `Assets/_Project/Scenes/Main.unity` и нажать Play.

## Ограничения и известные проблемы

На ПК-сборке включается PC: мягкие тени, 4 каскада.
- Тени на Mobile жёсткие, на краях заметна «лесенка» — сознательная экономия; дальность теней 25 м подобрана под арену 10×10 и камеру `(0, 14, -11)`. При увеличении арены пересмотреть камеру и дальность теней.
- Юниты двигаются по прямой: проходят сквозь блоки и друг друга (поиска пути пока нет, DEC-017).
- Выделяется один юнит за раз; камера неподвижна.
- Партия проверена скриптовыми приказами в редакторе; баланс не настраивался, живыми людьми не играна.
- `com.unity.pipeline` — экспериментальный мост для Unity CLI в редакторе; в сборку не попадает (предупреждение `No RuntimePipelineConfig asset found` при сборке ожидаемо).

## Тесты

**Window → General → Test Runner**: вкладка EditMode (правила `Health`, `BattleRules`) и PlayMode (движение, атака, команды касанием через виртуальный Touchscreen, исход партии). Сейчас 9 + 22 теста, все проходят.
