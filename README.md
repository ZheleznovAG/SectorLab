# SectorLab

Учебный прототип мобильной тактической игры на Unity: 3D, вид сверху, целевая платформа Android. Контракт следующей v1.0 — **Relay Skirmish / Битва за узлы**: 3×3, два очковых узла и один ремонтный, AI, возрождение, короткая партия по очкам. План и требования — [`README_START.md`](README_START.md); фактический прогресс — [`IMPLEMENTATION_STATUS.md`](docs/agent_execution/IMPLEMENTATION_STATUS.md). Старый [`docs/03_ROADMAP.md`](docs/03_ROADMAP.md) хранит историю R0–R5.

**Текущее состояние:** W1 — правила 45 очков / 180 игровых секунд / Draw, часы, пауза и остановка боя при исходе. Бой 3 на 3 (Tank, Scout, Ranger с каждой стороны) сохранён на арене 10×10 м. Гибель команды больше не завершает матч. Следующий этап W2 подключает очковые и ремонтный узлы; до него обычная партия заканчивается ничьей по времени. Возрождение, AI за узлы и VContainer/UniTask/Addressables ещё предстоят.

## Как играть

- **Нажми на синего юнита** — он выделится жёлтым кольцом. Попадать точно не обязательно: касание в пределах ~7 мм от юнита засчитывается.
- **Нажми на землю** — выделенный юнит пойдёт туда (жёлтый маркер — точка назначения).
- **Нажми на красного врага** — выделенный юнит подойдёт и будет атаковать.
- Роли (форма одинакова у обеих сторон): **Tank** — широкий, медленный, живучий; **Scout** — маленький, быстрый, хрупкий, бьёт часто; **Ranger** — цилиндр, стреляет на 4 м (жёлтая линия выстрела).
- Стоящие юниты сами атакуют ближайшего врага: твои — в радиусе 2.5 м, враги — 4 м. Подводи врагов по одному.
- Вверху экрана — сколько юнитов осталось у каждой стороны; при попадании юнит вспыхивает белым.
- Матч заканчивается по очкам или через 180 игровых секунд; равенство даёт **Draw**. Кнопка **Restart** начинает партию заново. Узлы для начисления очков добавляются в W2; экранный HUD/кнопка паузы — в W6.

Мышь в редакторе и касание на телефоне обрабатываются одним кодом (`Pointer` из Input System).

## Требования

- Unity **6000.6.4f1** с модулем **Android Build Support** (OpenJDK, Android SDK & NDK).
- Git и **Git LFS** (бинарные ассеты хранятся через LFS).

## Запуск

1. Клонировать: `git clone https://github.com/ZheleznovAG/SectorLab.git`, затем `git lfs pull`.
2. Открыть папку проекта через Unity Hub.
3. Переключить платформу: **File → Build Profiles → Android → Switch Platform** (активная платформа хранится в `Library/`, поэтому свежий клон открывается под Windows).
4. Открыть сцену `Assets/_Project/Scenes/Main.unity` и нажать Play.

## Сборка Android

**File → Build Profiles → Android → Build** (или из терминала через Unity CLI: `unity command build --target Android --outputPath Builds/Android/SectorLab.apk --confirm true` при открытом редакторе). Папка `Builds/` в Git не попадает.

Идентификатор пакета: `com.zheleznovag.sectorlab`. Ориентация: только горизонтальная (Landscape Left/Right).

## Ограничения и известные проблемы

- **Не проверено на реальном устройстве.** APK собирается без ошибок, но запуск на телефоне ещё не выполнялся.
- При аудите W0 ADB обнаружил подключённый Redmi Note 8 Pro; это подтверждает доступность устройства, запуск игры на нём ещё предстоит.
- Редактор показывает уровень качества **Mobile** (как на телефоне). На ПК-сборке включается PC: мягкие тени, 4 каскада.
- Тени на Mobile жёсткие, на краях заметна «лесенка» — сознательная экономия; дальность теней 25 м подобрана под арену 10×10 и камеру `(0, 14, -11)`. При увеличении арены пересмотреть камеру и дальность теней.
- Юниты ходят по NavMesh и обходят блоки; при изменении арены сетку нужно перепечь (DEC-017).
- Блоки и стены слоя Default препятствуют атаке между центрами юнитов; атакующий пытается сблизиться до прямой видимости. Триггеры не блокируют атаку. При новых слоях геометрии обновить `Obstruction Mask` в `UnitAttack`.
- Допуск касания проверяет видимость центра юнита; если центр закрыт, неточное нажатие его не выбирает. Прямое попадание в видимую часть коллайдера продолжает работать.
- Частичный путь заканчивается на доступной границе NavMesh, даже если запрошенная точка не достигнута. Обратной связи о причине такой остановки пока нет.
- Автоматическое преследование повторяет запрос пути не чаще раза в 0,5 с, в том числе для недостижимой цели. Новый явный приказ атаки запускает преследование сразу. При немедленном отказе приказа движения прежняя цель атаки сохраняется; принятый приказ отменяет атаку, даже если рассчитанный позже путь частичный.
- Выделяется один юнит за раз; камера неподвижна.
- Партия проверена скриптовыми приказами в редакторе; баланс не настраивался, живыми людьми не играна.
- `com.unity.pipeline` — экспериментальный мост для Unity CLI в редакторе; в сборку не попадает (предупреждение `No RuntimePipelineConfig asset found` при сборке ожидаемо).

## Тесты

**Window → General → Test Runner**: вкладка EditMode (правила `Health`, `BattleRules`) и PlayMode (движение, атака, команды касанием через виртуальный Touchscreen, исход партии). На 11.10.2026 проверено 9 EditMode + 38 PlayMode, все проходят. Новые проверки покрывают закрытую цель, обход препятствия при атаке, скрытого юнита, отключённый агент, отказ приказа и фактическое прохождение частичного пути. Дополнительно проверены ограничение повторных попыток к недостижимой цели и возобновление атаки после открытия пути.
