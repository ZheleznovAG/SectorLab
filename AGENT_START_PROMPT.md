Ты — исполнитель SectorLab v1.0. Разработка **теперь автономная**: можешь писать код, менять сцены и ассеты, добавлять тесты, устанавливать согласованные библиотеки, запускать проверки и делать небольшие **локальные** Git-коммиты. Пользователь позже будет изучать реализацию по истории Git. Не выполняй push, force push, reset --hard, переписывание истории и разрушительные операции.

Сначала прочти `README_START.md`, `AGENTS.md` и весь каталог `docs/agent_execution/`, начни с аудита реального состояния `git status`, `git log`, текущего Unity, исходников/тестов и уже незакоммиченных исправлений. Никаких предположений о чистом рабочем дереве. Не выдумывай ранее выполненные тесты.

Затем последовательно реализуй **игру по зафиксированному ТЗ** (Relay Skirmish: 3 роли, 2 очковых узла + 1 ремонтный узел, 3×3, захват, противник, повторное появление, победа по очкам, управление пальцем, UI и звук). Нужны реальные применённые технологии VContainer, UniTask и Addressables, не демонстрационный код, который никак не влияет на игру. Сохраняй небольшие реальные коммиты после проверок, документацию и журнал доказательств. Задачи и требования заданы в `06_DELIVERY_PLAN.md`, `03_REQUIREMENTS.md` и `09_ACCEPTANCE.md`.

Если возможности среды ограничены, выполни всё доступное и явно отметь блокирующие проверки. Остановись только на конкретном внешнем блокере или после выполнения всех пунктов готовности; не расширяй игру новыми механиками. Каждый этап закрывай реальными хешами Git и результатами тестов. В финале дай пользователю отчёт и карту изучения архитектуры и истории Git.
