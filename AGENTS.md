# AGENTS.md — SectorLab

Точка входа для любого агента (Claude Code, Codex, Cursor и т. п.) и для человека, впервые открывшего
репозиторий. Прочитай этот файл целиком: за 5 минут станет понятно, что за проект, в каком он
состоянии и как в нём работать.

## Что это

**SectorLab: Relay Skirmish** — мобильная тактика на Unity 6. Три робота против трёх на маленькой
арене захватывают узлы: кто первым набрал 45 очков или ведёт через 180 секунд, тот победил.
Противник — ИИ или второй человек по Wi-Fi. Учебный портфолио-проект владельца (`ZheleznovAG`),
разработанный с участием AI; это не коммерческий продукт.

Зачем он существует и что в него не входит — [docs/MISSION.md](docs/MISSION.md).

## Как работать

### Перед началом

```sh
git status --short && git log --oneline -10    # чужие незакоммиченные правки не трогать без спроса
python Tools/sl.py doctor                      # что доступно: Unity Editor, gitleaks, adb, телефон
```

### Правила

- **Честность проверок.** «Работает на телефоне» и «проверено человеком» пишутся только после реальной
  проверки. Не подделывать результаты тестов, даты, скриншоты, хеши. Непроверенное помечать как непроверенное.
- **Коммиты.** Маленькие, одна законченная проверенная правка; сообщение по-английски в стиле
  `type: summary` (`feat`, `fix`, `refactor`, `test`, `docs`, `build`, `chore`), тело объясняет *почему*. **Без трейлера `Co-Authored-By`.** Автор — GitHub noreply (проверяет pre-commit хук). Перед `git commit` проверь `git diff --cached --stat`: в индексе не должно быть лишнего.
- **Нельзя:** `push --force`, `rebase`, `reset --hard`, `clean -fdx`, переписывание истории, удаление чужих
  файлов без проверки. Новое архитектурное решение —
  новый ADR по [шаблону](docs/templates/ADR.md). Язык документации — русский, имена API — как есть.
- **Границы.** Не добавлять ECS/DOTS, собственный DI, глобальный EventBus, сетевые сервисы и платные
  ассеты без решения владельца. Предпочитать рабочую понятную игру абстракциям «на будущее».

### Проверка перед коммитом

```sh
python Tools/sl.py test --task <имя> --mode PlayMode --filter SectorLab.Tests.<Fixture>   # затронутое
python Tools/sl.py test --task <имя>                                                       # всё (~15–25 мин)
python Tools/sl.py check                                                                   # гигиена + приватность
```

Нужен открытый Unity Editor с проектом (`unity open .`). Отчёты пишутся в `docs/evidence/`.
Подробности и подводные камни — [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Технологии

Unity **6000.6.4f1**, URP 17.6, Input System 1.20, AI Navigation 2.0 (NavMesh), uGUI. VContainer 1.19
(composition root матча), UniTask 2.5 (загрузка и возрождение с отменой), Addressables 2.11 (локальные
префабы юнитов), R3 1.3.1 (реактивная модель матча), Unity Transport 6.6 (UDP для сетевой игры).
Цель — Android (landscape); разработка и тесты — в Editor. Инструменты разработчика — Python 3.9+.
